MATCHLAB — ГЛАВНАЯ И БЛИЖАЙШИЕ МАТЧИ

Откройте index.html или matches.html. Данные теперь доступны даже при обычном открытии файла: сервер для просмотра выгрузки не нужен.

Убраны поясняющий текст и переключатель демонстрационных данных со скриншота. Вымышленные команды удалены. Страница матчей открывается с фильтром «Все даты». Кнопка «Показать ещё» всегда видна и раскрывает по 6 строк; после конца списка она неактивна. «Архив результатов» содержит сыгранные матчи двух сезонов, результаты и статистику.

ИСТОЧНИКИ

Статистика: свежий архив https://github.com/kazakovla/MatchLab
110 команд, 3504 строки исторических матчей сезонов 2024/25 и 2025/26. Отчёт расчёта индекса использует 3503 матча: одна строка не имеет нужной статистики. В архиве интерфейса сохранены все исходные CSV и corner_index.json/csv в data/source.

Расписание: https://www.football-data.co.uk/fixtures.csv — именно этот адрес указан в конфигурации backend из репозитория. На момент скачивания 21.09.2026 источник содержит 48 матчей пяти лиг за 18–20 сентября 2026. Будущего расписания на 21 сентября и позже в файле нет. Прошедшие записи расписания не выдаются за предстоящие; счёт по ним неизвестен. Главная честно показывает отсутствие будущих матчей.

Индексы и средние показатели — готовая историческая выборка из репозитория, а не пересчёт на дату каждой игры. Период статистики подписан в карточке. У новых команд без совпадения по лиге и имени индекс не придумывается. Для времени использован Europe/London, как в конфигурации исходного backend; показ на странице — Europe/Moscow. Догадку о поясе источника автор backend отдельно отмечает в своём README, она не подтверждена независимо.

ОБНОВЛЕНИЕ ДАННЫХ

Если установлен Node.js, откройте терминал в папке сайта и выполните:
node sync-data.cjs

Команда скачивает статистику из GitHub и расписание с football-data.co.uk, затем пересобирает data/matchlab-data.js. Обновите страницу браузера. Если источник ещё не выложил новое расписание, будущие матчи не появятся. Автоматического фонового обновления нет.

Для пересборки из локальных исходников без интернета:
node sync-data.cjs --local

BACKEND

Это рабочая интеграция файлов данных с интерфейсом, а не запущенный NestJS-сервер. В GitHub по-прежнему опубликован отдельный модуль matches без package.json, bootstrap и реализаций импортируемых Prisma/Redis-сервисов. Мы не подменяем его вымышленным работающим API.

Новая страница читает выгрузку из data/matchlab-data.js. Главная также читает её по умолчанию. Если указать apiBaseUrl в config.js, главная использует ранее подготовленный /api/v1/matches/upcoming. Остальные разделы, авторизация и статьи не реализованы дополнительно.

serve.cjs остаётся необязательным локальным статическим сервером: node serve.cjs, затем http://127.0.0.1:5500.

ПРОВЕРКА

Проверены данные (48 записей календаря, 3504 исторических матча, 760 матчей Премьер-лиги), фильтры, подробности, раскрытие списка, постоянная видимость и неактивное состояние кнопки в конце списка, локальное открытие без сервера, главная и адаптивность 320–1440 px. Запущенный NestJS/PostgreSQL/Redis не проверялся.
